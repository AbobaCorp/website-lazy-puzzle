# Собери Руслана

Онлайн-игра в пазл: собери по кусочкам четыре фото Руслана. Без подсказок, с поворотами и таймером.

## Описание

Простая браузерная игра-пазл с юмористическим уклоном. Игрок собирает четыре изображения Руслана, уровень за уровнем. Сложность растёт: больше кусочков, повороты, режим обмена местами и ограничение по времени.

Игра полностью работает в браузере, без сервера и внешних зависимостей (кроме Google Fonts).

## Возможности

- **4 уровня** с возрастающей сложностью
- **Два режима**:
  - Свободное перетаскивание кусочков (уровни 1–3)
  - Обмен кусочков местами (уровень 4)
- Поворот кусочков (клик или клавиша `R`)
- Таймер и счётчик ходов
- Звуковые эффекты (можно отключить)
- Адаптивная вёрстка под разные экраны
- Поддержка мыши и тач-устройств

## Уровни

| Уровень | Сетка (примерно) | Особенности |
|---------|------------------|-------------|
| 1. Разминка для лентяя | 3×n | Простое перетаскивание |
| 2. Уровень 2 | 4×n | Таймер + счётчик ходов |
| 3. Кусочки спят | 5×n | Часть кусочков повёрнута |
| 4. Финальный босс | 6×n | Обмен местами, повороты, лимит 10 минут |

## Запуск

1. Скачайте или клонируйте проект.
2. Откройте `index.html` в любом современном браузере  
   (можно просто дважды кликнуть по файлу или запустить локальный сервер).

```bash
# Пример с Python
python -m http.server 8000
# затем откройте http://localhost:8000
```

Никакой сборки и установки зависимостей не требуется.

## Управление

| Действие | Как |
|----------|-----|
| Переместить кусочек | Перетащить мышкой / пальцем |
| Повернуть кусочек | Клик по кусочку (в режимах с поворотами) или клавиша **R** |
| Выбрать и поменять местами | Клик по первому, затем по второму (уровень 4) |
| Сдаться | Кнопка «Сдаться: любимое занятие» |

## Технологии

- Чистый HTML5 + CSS3 + JavaScript (ES6+)
- Canvas для нарезки изображений на кусочки
- Pointer Events для удобной работы с мышью и тачем
- Web Audio API для простых звуков
- Шрифт [Rubik](https://fonts.google.com/specimen/Rubik)
